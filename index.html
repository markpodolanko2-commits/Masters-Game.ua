Готовий до пригод?

Приєднуйся до сервера

Скопіюй адресу, відкрий Minecraft і додай сервер до списку.

JAVA EDITION

Грай на Java

Відкрий Multiplayer, натисни Add Server та введи адресу сервера.

SERVER ADDRESSmysterious-game.pp.ua
⚒
BEDROCK EDITION

Грай на Bedrock

Додай сервер у розділі Servers. Для Bedrock необхідно знати справжній мережевий порт.

SERVER ADDRESSmysterious-game.pp.ua
◇

Адреса та підтримка Java/Bedrock вказані за наданими даними. Фактичну доступність сервера, сумісність версій і порт Bedrock потрібно перевірити.

Підтримай проєкт

Магазин привілеїв

Переглянь доступні ранги, їхні можливості та вартість. За наданою інформацією, видача рангів відбувається вручну після фінансової підтримки сервера.

Як отримати ранг?

Наразі ранги видаються вручну. Перед оплатою уточни спосіб переказу, свій ігровий нікнейм і термін видачі в адміністрації.

Уточнити в Discord ↗

Вартість указана в гривнях відповідно до наданого опису. Оплата на сайті не реалізована. Перевір характеристики рангів перед публікацією, особливо успадкування можливостей і назву рангу за 100 грн.
